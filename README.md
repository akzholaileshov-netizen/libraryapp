# Электронды кітапхана

Flask және SQLite негізіндегі қарапайым электронды кітапхана веб-қолданбасы. Кітаптарды қосу, каталогта қарау, іздеу, өңдеу және жою мүмкіндігі бар.

## Мүмкіндіктер

- **Кітап қосу** — атауы, авторы, жылы, жанры
- **Каталог** — кесте түрінде барлық кітаптарды қарау
- **Іздеу** — атауы / авторы / жанры бойынша
- **Өңдеу және жою** — жазбаларды өзгерту немесе өшіру
- **Валидация** — бос өрістер қабылданбайды; жыл бүтін сан болуы керек
- **Бастапқы деректер** — бос базаға бірнеше үлгі кітап автоматты түрде қосылады

## Орнату және іске қосу

### Талаптар

- Python 3.10+

### Қадамдар

```bash
# Тәуелділіктерді орнату
pip install -r requirements.txt
# немесе: pip3 install -r requirements.txt

# Қолданбаны іске қосу (порт 5055, host 0.0.0.0)
python3 run.py
# python қолжетімді болса: python run.py
```

Браузерде ашыңыз: [http://127.0.0.1:5055](http://127.0.0.1:5055)

Балама (Flask CLI):

```bash
export FLASK_APP=run.py
export PATH="$HOME/.local/bin:$PATH"
flask run --host=0.0.0.0 --port=5055
```

SQLite файлы `instance/library.db` жолында автоматты түрде жасалады (кесте схемасы іске қосу кезінде құрылады).

## Жоба құрылымы

```
.
├── app/
│   ├── __init__.py      # Flask қолданбасын құру
│   ├── db.py            # SQLite: схема, seed, CRUD
│   ├── routes.py        # Маршруттар және валидация
│   ├── static/css/      # Стильдер
│   └── templates/       # HTML үлгілері (Bootstrap)
├── instance/            # SQLite дерекқор файлы (gitignore)
├── requirements.txt
├── run.py               # Іске қосу нүктесі
└── README.md
```

## Өндіріс / деплой

Қоршаған орта айнымалылары:

| Айнымалы | Сипаттама | Әдепкі |
|----------|-----------|--------|
| `HOST` | Тыңдау хосты | `0.0.0.0` |
| `PORT` | Порт | `5055` |
| `SECRET_KEY` | Flask secret | dev мәні |
| `DATABASE_PATH` | SQLite файл жолы | `instance/library.db` |
| `FLASK_DEBUG` | `1` болса debug | `0` |

Gunicorn:

```bash
pip install -r requirements.txt
gunicorn run:app --bind 0.0.0.0:${PORT:-5055}
```

`render.yaml` — Render Blueprint (free web service). Railway/Fly үшін `Procfile` қолданылады.
